Cấu hình Google Drive Sync

Chưa cấu hình bộ nhớ đám mây...

TG-Task hỗ trợ **Google Drive** để lưu trữ và đồng bộ hóa công việc thời gian thực một cách bảo mật. Dữ liệu của bạn được lưu trong một file ẩn riêng trên Drive cá nhân, đảm bảo an toàn tuyệt đối.

💡 Hướng dẫn lấy Client ID cực nhanh trong 1 phút:

  1. Truy cập Google Cloud Console và tạo 1 dự án mới.
  2. Vào mục APIs & Services -> Library, tìm và bật (Enable) Google Drive API.
  3. Vào mục OAuth consent screen, chọn User Type là External, điền tên app (ví dụ: TG-Task) và email của bạn rồi bấm Save.
  4. Vào mục Credentials -> Bấm Create Credentials -> Chọn OAuth client ID.
  5. Chọn Application type là Web application. Tại mục Authorized JavaScript origins, thêm đường dẫn trang của bạn: https://yangkoi.github.io (và http://localhost:5500 hoặc http://127.0.0.1:5500 để chạy thử local). Bấm Create và copy mã Client ID dán vào đây!
